# Exercícios de SQL (iniciantes)

Tente responder antes de abrir `sql/02_consultas_iniciais.sql`:

1. Quais são as dez primeiras vendas da tabela? (`SELECT`, `LIMIT`)
2. Qual é a receita total das vendas? (`SUM`)
3. Qual unidade vendeu mais? (`GROUP BY`, `ORDER BY`)
4. Qual produto teve maior receita? (`GROUP BY`)
5. Qual foi o percentual de meta de cada unidade em janeiro? (`JOIN` + cálculo)

**Desafio opcional:** criar a consulta de faturamento por mês, com `substr(data_venda,1,7)`.

## Reflexões para o README

- O que você descobriu ao consultar os dados?
- Quais unidades ficaram abaixo da meta em algum mês?
- Que ações poderiam ser investigadas para melhorar o resultado?

**Importante:** como a base é inventada, as conclusões são exercícios analíticos, não recomendações reais de negócio.
